Créditos

O ShowVault junta dados de várias fontes abertas. Obrigado a quem mantém cada uma delas. O ShowVault é um projeto não oficial.

TMDB

This product uses the TMDB API but is not endorsed or certified by TMDB.

Este produto usa a API do TMDB, mas não é endossado nem certificado pelo TMDB. Capas e miniaturas de séries e filmes vêm do TMDB.

themoviedb.org

TVMaze

Dados de séries também do TVMaze, sob a licença CC BY-SA 4.0.

tvmaze.com

AniList e Jikan

Dados de animes da AniList (fonte principal) e, como reserva, da Jikan (API não oficial do MyAnimeList). O ShowVault é não oficial e não é afiliado a nenhuma delas.

anilist.co jikan.moe

Mapa de ids dos animes

Para achar títulos e miniaturas de episódio no TMDB: Fribb/anime-lists, que reúne dados do anime-offline-database (licença ODbL 1.0) e do Anime-Lists (ScudLee). Baixado na hora do uso, sem cópia no código.

Fribb/anime-lists anime-offline-database Anime-Lists
